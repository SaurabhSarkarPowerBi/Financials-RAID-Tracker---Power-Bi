**** Project Financial & RAID Tracker Dashboard | Power BI ****

An end-to-end Power BI project designed to provide executive-level visibility into project financials, budget performance, invoicing, RAID management (Risks, Assumptions, Issues & Dependencies), stakeholder engagement, and deliverable tracking.

This solution was independently designed, modelled, developed, and documented to replicate a real-world PMO/Project Governance dashboard commonly used by senior leadership teams, project managers, and client stakeholders.

**** Project Overview ****
This dashboard consolidates multiple project management functions into a single interactive reporting solution, enabling stakeholders to:

 ✅ Monitor budget vs actual spend performance
 ✅ Track invoicing and outstanding financial exposure
 ✅ Manage RAID logs and escalation risks
 ✅ Monitor deliverable health and project milestones
 ✅ Analyze stakeholder engagement and communication requirements
 ✅ Support executive decision-making through KPI-driven insights

The solution mirrors enterprise project governance practices and demonstrates expertise across:

Power BI Data Modeling
Data Transformation & ETL
DAX Measure Development
Financial Analytics
Project Portfolio Reporting
RAID Governance
Stakeholder Management Reporting
Executive Dashboard Design
